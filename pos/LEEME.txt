================================================================================
HAFID POS — CONTINUAR EN OTRA PC (lee esto primero)
================================================================================

Repo: https://github.com/franckococco/erp-repuestos
Carpeta del POS: erp-repuestos\pos\

--------------------------------------------------------------------------------
1) ABRIR EN ESTA PC (3 pasos)
--------------------------------------------------------------------------------
  a) Abrí una terminal en erp-repuestos y hacé:
       git pull

  b) Entrá a la carpeta pos y (solo la primera vez) instalá deps:
       cd pos
       pip install -r requirements.txt

  c) Doble click en:
       ABRIR_POS.bat

  d) En el navegador abrí:
       http://127.0.0.1:8766

--------------------------------------------------------------------------------
2) FIREBASE (datos reales)
--------------------------------------------------------------------------------
  En esta PC todavía puede faltar firebase_claves.json.

  Copiá el archivo a:
    erp-repuestos\firebase_claves.json
  (junto a app.py — NO dentro de pos\ obligatoriamente)

  Cómo conseguirlo:
  - De Streamlit Cloud → Settings → Secrets → bloque [firebase_key]
    (pasalo a formato JSON de cuenta de servicio), O
  - Firebase Console → Project settings → Cuentas de servicio →
    Generar nueva clave privada → renombrar a firebase_claves.json

  Después en el POS tocá el botón "Conectar Firebase" (banner amarillo).

  NUNCA subas firebase_claves.json a GitHub (tiene secretos).

--------------------------------------------------------------------------------
3) QUÉ YA ESTÁ HECHO (emulador / presupuestos)
--------------------------------------------------------------------------------
  - Pantalla rápida: búsqueda arriba, resultados abajo, carrito al costado
  - Sin recargar toda la página (no es Streamlit)
  - Tip: escribí 111*3 y Enter → agrega 3 unidades
  - Atajos: F2 buscar · F3 cliente · F4 presupuesto · F6 en espera · Esc limpia
  - Ctrl+Z deshacer · carritos "En espera"
  - PDF presupuesto, historial (cargar / duplicar / actualizar / anular)
  - Precio, cantidad y descripción editables · ítem manual · descuento
  - Stock bajo marcado · varias marcas del mismo código
  - Factura ARCA: DEJADA PARA EL FINAL (no usar todavía)

  Streamlit del ERP sigue igual para administración. Este POS es el mostrador nuevo.

--------------------------------------------------------------------------------
4) QUÉ FALTA (orden)
--------------------------------------------------------------------------------
  1. Conectar Firebase en cada PC (claves locales)
  2. Probar presupuestos con inventario/clientes reales
  3. Factura ARCA + ticket + descontar stock (al final)
  4. Cuando esté estable, enlazar / reemplazar el mostrador Streamlit

--------------------------------------------------------------------------------
5) PARA QUE CURSOR SIGA EL HILO EN LA OTRA PC
--------------------------------------------------------------------------------
  Abrí Cursor en erp-repuestos, chat nuevo, y pegá el contenido de:
    pos\PEGAR_EN_CURSOR.txt

  Ahí está el resumen del hilo para que el agente continúe sin perder contexto.

--------------------------------------------------------------------------------
6) SI ALGO FALLA
--------------------------------------------------------------------------------
  - Puerto 8766 ocupado: cerrá la ventana negra del POS anterior
  - pip / python: instalá Python 3.11+ y volvé a pip install -r requirements.txt
  - Sigue en emulador: falta firebase_claves.json o no tocaste "Conectar Firebase"
